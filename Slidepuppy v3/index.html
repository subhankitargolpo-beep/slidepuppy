How to Use SlidePuppy

Step 1: Get Your API Keys

  1. Click the ⚙️ Settings button on the main page.
  2. You need a Gemini API key. Go to the Google AI Studio website: https://aistudio.google.com/app/apikey.
  3. Click "Create API key in new project" and copy the key.
  4. Paste this key into the "Gemini API Key" field in the settings and click the save icon. Your key is saved locally in your browser.

(Optional) Custom Web Search Keys

  1. For heavy use or more control over search results, you can use your own Google Search API.
  2. In Settings, find the "Advanced" section, check "Enable Custom Search", and provide your Google Search API Key and Search Engine ID. Click "Save Search Keys".
  3. You can get these from the Google Programmable Search Engine control panel.

Step 2: Fill Out the Presentation Details

  1. Topic: Enter the main subject of your presentation. You can paste a whole lesson plan or just a few words.
  2. Difficulty & Detail: Adjust the sliders. "Difficulty" affects complexity, while "Detail" controls the amount of text per slide.
  3. Audience, Purpose, etc: Select the options that best describe your presentation's goal and tone.
  4. Customization: Add a footer, choose a brand color for the title/end slides, and upload your own images from your computer.
  5. Custom Slides: Click "Add Slide" to give the AI a specific instruction for a slide, like "Create a table comparing X and Y."

Step 3: Generate, Edit, and Download

  1. Click the "Generate Presentation" button and wait for the AI agents to finish.
  2. Review the slides in the preview panel. Click "Fullscreen Editor" for more control.
  3. In the editor, you can edit text directly on the slide. On the right, assign images from your library to the current slide, or search for new ones.
  4. Use the "AI Edit" button on any slide to ask for changes, like "Make this slide more concise."
  5. When you're happy, exit the editor and click "Download .PPTX".
